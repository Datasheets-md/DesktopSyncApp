# datasheets-md-gui

dBsync, the desktop app for [datasheets.md](https://datasheets.md).

```bash
pip install datasheets-md-gui
dsmd-gui            # or: dsmd gui
```

Installs [datasheets-md](https://pypi.org/project/datasheets-md/) (the `dsmd`
CLI) together with the PySide6 GUI. On a machine that already has
datasheets-md, it only adds the GUI packages.
